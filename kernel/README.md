# Squirrel-OS/2 Kernel

Original bare-metal x86 kernel. It is not derived from osFree, Voyager, or any other external OS/2 source.

The image is a 512-byte boot sector (`boot.asm`) followed by a flat 96 KB kernel (`pm.asm`, 192 sectors), which is loaded at `0x8000`.
The other `.asm` files here are included from `pm.asm`.

| File | What it is | Design note |
|------|------------|-------------|
| `boot.asm` | Boot sector: loads the kernel with extended or CHS disk reads | `documentation/kernel/boot-sector.md` |
| `pm.asm` | Stage 2 (CPU check, memory map, protected mode), IDT, PIT, keyboard, console, built-in commands | `documentation/architecture/overview.md` |
| `syscall.asm` | `int 0x80` system calls | `documentation/kernel/syscalls.md` |
| `proc.asm` | Processes, cooperative scheduler | `documentation/kernel/processes.md` |
| `mm.asm`, `vm.asm` | Page allocator, paging, per-program address spaces | `documentation/kernel/memory.md` |
| `dev.asm`, `chardev.asm`, `ata.asm` | Driver table, `con`/`kbd`, ATA PIO disks | `documentation/kernel/drivers.md`, `block-device.md` |
| `fs.asm` | SQFS file system with directories | `documentation/kernel/filesystem.md` |
| `shell.asm`, `lineedit.asm`, `batch.asm` | Pipes and redirection, line editing and history, batch files | `documentation/kernel/shell.md` |
| `loader.asm` | SQX and ELF32 program loader | `documentation/kernel/loader.md` |
| `lang.asm`, `strings.inc` | Localization (`strings.inc` is generated by `tools/mkstrings.py`) | `documentation/kernel/localization.md` |
| `crash.asm` | Crash reports | `documentation/kernel/crash-reports.md` |
| `browser.asm`, `calc.asm`, `sci.asm`, `matrix.asm`, `diff.asm`, `editor.asm`, `draw.asm` | The applications | `documentation/apps/` |

`arch/`, `common/`, `loaders/` and `personalities/` hold scaffolds for later eras (other CPUs, foreign personalities). They are not built.

## Build & run

```bash
tools/build.sh      # build/os.img, build/floppy.img, build/data.img
tools/run.sh        # start QEMU
tools/regress.sh    # regression suite
```

Requires NASM, QEMU and Python 3. See `documentation/guides/getting-started.md`.
