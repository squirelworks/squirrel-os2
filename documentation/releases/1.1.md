# 1.1 — Preemption and threads

- Date: 2026-10-31
- Goal (from `ROADMAP.md`): milestone 1.1, a preemptive scheduler and threads, after the 1.0.x patch releases that close the holes 1.0.0 named.
- What 1.1 is: everything merged since the `v1.0.0` tag, up to and including 1.1.1 (PRs #31–#45). The banner says `Squirrel-OS/2 1.1.1`. 1.2.0 (message queues, PR #46) is not part of it. Each item links to its own patch note.
- Changes:
  - **Scheduling and processes.**
    - The timer preempts a loaded program after a 50 ms slice (5 ticks), so a program that spins without a system call no longer starves the others. Kernel code is still switched only cooperatively (`1.1.0.md`; `sched-preempt`).
    - A `spawn` whose entry is in the program's own image is a thread. It shares the program's code, data and heap, and has its own pid, stack, FPU registers and exit code (`1.1.1.md`; `thread`).
    - Each process keeps its own x87 registers across a switch, so `sci`, `matrix` and programs may use floating point at the same time (`1.0.1.md`; `fpu-switch`).
    - Zombies nobody can wait for are freed, and `spawn` reclaims the oldest zombie when the table is full (`1.0.4.md`; `zombie`, `zombie-ps`).
  - **Files.**
    - `SYS_SEEK` (25) moves a descriptor's position. A position before the start or past the end is refused, so files never get holes (`1.0.2.md`; `seek`).
    - `SYS_FSERROR` (26) tells a program why its last file call failed, in the words the shell prints (`1.0.3.md`; `errno-*`).
    - 27 system calls (0–26).
  - **Localization.**
    - The shell's usage lines and every file-system error reason follow `lang` (`1.0.5.md`; `l10n-*`).
    - The `calc`, `edit` and `draw` titles follow `lang` (`1.0.6.md`).
  - **`diff` is no longer a scaffold.**
    - `d <f(x)> at <x0>`: numerical derivative (`1.0.7.md`).
    - `i <f(x)> from <a> to <b>`: numerical integral, composite Simpson on 1000 panels (`1.0.8.md`).
    - `euler <f(x,y)> from <x0> to <x1> y0 <y0> step <h>`: y′ = f(x, y) by Euler's method (`1.0.10.md`).
  - **Editors.**
    - Ctrl+F searches in `edit` and `vedit`, and F3 repeats the search (`1.0.9.md`).
    - Ctrl+Z undoes the last edit, one level (`1.0.11.md`).
    - Ctrl+T in `vedit` shows control characters: `$` for a line end, `>` for a tab, `^` for the rest (`1.0.12.md`).
  - **New test programs** on the program disk: `fpu`, `seek`, `errno`, `zombie`, `spin` and `thread`.
- How to build and run: unchanged. `tools/build.sh`, then `tools/run.sh`. See `guides/getting-started.md`.
- Tested on:
  - QEMU 8.2: `bash tools/regress.sh` on 5db33a6, 231 of 231 checks pass (183 at 1.0.0).
  - Bochs (`tools/bochs_smoke.sh`) was not rerun for this note.
  - Not yet on VirtualBox, VMware or real hardware.
- Known limitations: `specifications.md` (0.9.3 table, minus the items the 1.0.x and 1.1 sections remove). The main ones:
  - Built-in apps and long system calls are not preempted; they run until they yield or block.
  - No priorities (a 2.0 item).
  - No locks or other synchronization calls for threads; they coordinate through `yield`, `wait` and single-instruction updates.
  - Everything runs in ring 0.
  - `graph` and `topo` are scaffolds.
  - The apps' help text is still English apart from their titles.
- Gone since 1.0.0: cooperative-only scheduling, no FPU save, no seek, zombies filling the table, `diff` as a scaffold.
- Known bugs: none open (`knownbugs.md`).
- Next: milestone 1.2 in `ROADMAP.md` / `TODO.md` (1.2.0, message queues, is already merged).
- Status: ready to tag (`v1.1.1` on 5db33a6, the merge of PR #45).

## Tag and release steps

Run these from a clone with push access. The tag goes on the merge of PR #45, not on `main`, because `main` already has 1.2.0.

```sh
git fetch origin main --tags
git log -1 --format='%h %s' 5db33a6     # Merge pull request #45 from squirelworks/thread-1.1
git tag -a v1.1.1 5db33a6 -m "Squirrel-OS/2 1.1.1: preemption and threads"
git push origin v1.1.1
```

Then publish the release with this file as its body (the GitHub CLI drops the first heading line here, as the `v1.0.0` release did):

```sh
tail -n +3 documentation/releases/1.1.md | sed '/^## Tag and release steps/,$d' > /tmp/notes-1.1.md
gh release create v1.1.1 --verify-tag --title "1.1 — Preemption and threads" --notes-file /tmp/notes-1.1.md
```

Afterwards, change the Status line above to `released (tag v1.1.1 on 5db33a6, published <date>: <release URL>)`, as `1.0.0.md` did.
