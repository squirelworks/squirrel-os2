# 1.0.2 — Seek on open files

- Date: 2026-10-31
- TODO.md task: **1.0-seek**.
- Changes:
  - **`SYS_SEEK` (25).** Moves a descriptor's position: `ebx` = fd, `ecx` = offset (signed), `edx` = 0 from the start, 1 from the current position, 2 from the end. It returns the new position.
    - A position before the start or past the end of the file is refused with −1 and the position is left unchanged, so files never get holes.
    - Reads and writes continue from the new position. A write in the middle overwrites.
    - The kernel routine is `fs_seek`, and the number is in `programs/sqx.inc`.
  - **New program `seek`.** It writes `abcd`, seeks to the second byte, reads `bcd`, checks that a seek past the end is refused, reads the last byte via `SEEK_END - 1`, deletes its file, and prints `seek: PASS`.
  - Banner `1.0.2`.
  - Regression check: `seek`. `up-ls` counts the new program.
- Status: implemented
- Design: `kernel/filesystem.md` (Seek), `kernel/syscalls.md`
