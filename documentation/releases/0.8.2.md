# 0.8.2 — Crash reports and shell restart

- Date: 2026-10-30
- Changes:
  - `kernel/crash.asm` replaces the one-line exception message:
    - the exception's name, and the process (pid and name) it hit
    - all general registers, and the error code where the CPU gives one
    - for page faults, the address plus read/write and missing/protection
    - the top of the stack
  - A fault in any process other than the shell ends just that process (before, only loaded programs; built-in apps halted the machine)
  - A fault in the shell offers Enter to restart the shell or R to reboot instead of hanging; faults during boot still halt
  - Processes have names (`PCB_NAME`): `shell`, the app's `run` name, or the program file. `ps` shows a NAME column.
  - Regression checks: `exception` (now with name and pid), `crash-regs`, `crash-name`, `crash-restart`, `ps-name`, updated `vm-crash-addr`
- Status: implemented
- Design: `documentation/kernel/crash-reports.md`

This completes the 0.4–0.8 laundry list.
