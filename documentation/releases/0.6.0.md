# 0.6.0 — Physical page allocator

- Date: 2026-10-30
- Changes:
  - Real-mode `stage2` enables A20 (port `0x92`) and reads the BIOS E820 memory map
  - `kernel/mm.asm`: 4 KB page allocator over usable RAM from 1 MB to 256 MB, with a free list threaded through free pages and a bitmap that rejects bad and double frees
  - Syscalls `SYS_PALLOC` (19) and `SYS_PFREE` (20)
  - Shell: `mem` (memory map and page counts) and `memtest` (allocate everything, verify, free, verify)
  - Help text lists `echo`, `batch`, `mem` and `memtest`
  - Regression checks: `mem`, `mem-e820`, `memtest` (run twice in a row)
- Status: implemented
- Design: `documentation/kernel/memory.md`

Next: per-process address spaces (0.6.1).
