# 1.0.5 — Localized usage lines and file-system errors

- Date: 2026-10-31
- TODO.md task: **1.0-l10n-shell**.
- Changes:
  - **New string keys.** There are 17 new keys in `localization/{en,la,tlh}/strings.txt` (`kernel/strings.inc` is regenerated):
    - `usage`, for the word in front of each usage line;
    - `usage_put` and `usage_run`, for the hints after `put` and `run`;
    - one key per file-system error reason (`fe_error` … `fe_nofd`).
  - **File-system errors follow `lang`.**
    - `fs_errkey` maps each `FE_*` code to its key, and `fs_errstr` gives the text in the current language.
    - The shell, the editors' and `draw`'s message lines, and `SYS_FSERROR` all use it.
    - The English literals and the `fs_errmsg` pointer table are gone.
    - "No file system mounted" and "No such directory" from `cd` use the keys too.
  - **Usage lines follow `lang`.** The usage table now holds the command, its syntax and an optional hint key. The localized `usage` word comes first and the syntax is printed as typed. English output is unchanged.
  - Examples:
    - `lang la`, then `mkdir`, prints `Usus: mkdir <dir>`.
    - `lang tlh`, then `rm nosuch`, prints `tu'lu'be'`.
    - `lang tlh`, then making a directory that exists, prints `tu'lu'pu'`.
  - Banner `1.0.5`.
  - Regression checks: `l10n-usage-la`, `l10n-hint-la`, `l10n-fe-tlh`, `l10n-rm-tlh`. The English checks (`sh-usage`, `fs-e-*`, `ed-dir`, …) are unchanged.
