# 0.5.2 — Batch files

- Date: 2026-10-30
- Changes:
  - `kernel/batch.asm`: `batch <file>` and `run <name>.bat` run a script line by line; each line may use pipes and redirection
  - `#` comments, blank lines skipped, lines echoed as `> line` unless they start with `@`
  - Esc stops a script between lines; a script that starts another hands over to it
  - `autoexec.bat` on the data disk runs at boot
  - The pipeline driver is split into `sh_run_line` (one line) and `do_command` (line, then any queued script, then the prompt)
  - Regression checks: `bat-run`, `bat-quiet`, `bat-pipe`, `bat-chain`, `bat-missing`, `bat-autoexec`
- Status: implemented
- Design: `documentation/kernel/shell.md`

This completes the 0.5.x shell milestones. Next: memory management (0.6.0).
