# 0.1.2 — Basic process model

- Date: 2026-10-30
- Changes:
  - Process table (8 slots, 32-byte PCB), private 8 KB stacks, cooperative round-robin switch (`kernel/proc.asm`)
  - Syscalls `spawn` (4), `exit` (5), `wait` (6), `getpid` (7); `yield` now switches processes
  - `run <name>` spawns the app as a process and the shell waits for it; apps are table-driven (`run_table`)
  - Shell commands `ps` and `proctest` (three interleaving workers, reaped with exit codes)
  - Console/keyboard fixes (KB-1..KB-6): Shift and symbols, keypad `* - +`, signed numbers,
    scrolling with hardware cursor, single prompt when apps start, shell Backspace,
    CPU exception report (`*** CPU exception N at EIP ...`) instead of a silent hang
- Status: implemented
- Known limitations: no preemption, no memory protection, zombies without a waiter keep their slot (see `kernel/processes.md`)
- Design: `documentation/kernel/processes.md`, `documentation/kernel/syscalls.md`

Build/run: unchanged from 0.1.1. Regression: `tools/regress.sh` (21 checks).

Next: block device driver (0.2.0).
