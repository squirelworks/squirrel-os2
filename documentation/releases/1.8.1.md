# 1.8.1 — Installer: a bootable CD image

- Date: 2026-10-31
- TODO.md task: **I.6-cd**.
- Changes:
  - **`build/cd.iso`.** `tools/build.sh` also writes a bootable CD image with the new `tools/mkiso.py`: ISO 9660 with an El Torito boot record in floppy emulation around `floppy.img`. The BIOS boots it as floppy drive 0, so the kernel loads exactly as from a floppy. The ISO file system itself is empty.
  - `tools/qemu_screen.py --cdrom` boots an ISO image.
  - Banner `1.8.1`.
  - Regression checks: `cd-boot` (the CD boots to the shell) and `cd-data` (the data disk is found when booted from the CD).
- Known limitations:
  - The kernel has no CD-ROM (ATAPI) driver, so a system booted from the CD cannot read its kernel back: `install copy` and `run install` refuse with `The boot disk is not an IDE disk`. Installing from CD belongs with the Modern hardware milestone.
- Status: implemented
