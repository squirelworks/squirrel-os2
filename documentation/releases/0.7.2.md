# 0.7.2 — ATA disks as block devices

- Date: 2026-10-30
- Changes:
  - `ata.asm` registers `hd0` (boot disk, read-only for programs) and `hd1` (data disk); the probe takes the size found by `ata_init`
  - SQFS reads and writes through `hd1` (`FS_DEV`) instead of calling the ATA routines
  - `SYS_BREAD`/`SYS_BWRITE` go through the devices; drive numbers other than 0 and 1 are now refused instead of indexing past the size table
  - Regression checks: `devices`, `devices-nodisk`, `devtest`
- Status: implemented
- Design: `documentation/kernel/drivers.md`, `documentation/kernel/block-device.md`
