# 1.0.1 — FPU state saved per process

- Date: 2026-10-31
- TODO.md task: **1.0-fpu**. Required before preemption (1.1).
- Changes:
  - **Each process has its own x87 registers.** `proc_switch` saves the outgoing process's FPU state with `fnsave` and restores the incoming one's with `frstor`. A process that never had its state saved starts with a reset FPU (`fninit`). Each process slot has a 108-byte save area, `proc_fpu`.
  - **New program `fpu`.** It loads 12345 onto the FPU stack, then runs a second copy of itself that fills all eight registers with 7. It waits for that copy to finish, reads its own value back, and prints `fpu: PASS`. Before this change it printed `fpu: FAIL`.
  - `sci`, `matrix` and programs may now use floating point at the same time. `calculators.md` drops the "one process at a time" warning.
  - Banner `1.0.1`.
  - Regression check: `fpu-switch`. `up-ls` expects 16 files, because `fpu` is on the program disk.
- Status: implemented
- Design: `kernel/processes.md` (FPU state), `apps/calculators.md`
