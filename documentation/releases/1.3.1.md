# 1.3.1 — Lines and filled rectangles

- Date: 2026-10-31
- TODO.md task: **1.3-line-fill**.
- Changes:
  - `gfx_line` draws a line between two points with Bresenham's method, both ends included, in any direction. `gfx_fillrect` fills a rectangle, clipped to the screen. Both take the colour from `gfx_colour` (`kernel/gfx.asm`).
  - **`gfxprim`**, a new shell test command: clears the lower part of the screen, draws a line and a filled rectangle, reads back pixels on the line, inside the rectangle and just outside it, returns to text mode and prints `gfxprim: PASS` or `FAIL`.
  - The banner's test list moves `gfxtest` and `gfxprim` to a second line, so the first stays within 80 columns.
  - Banner `1.3.1`.
  - Regression checks: `gfxprim`; `gfxprim-text` (`systest` after `gfxprim`). With the line left out, `gfxprim` prints FAIL.
- Known limitations: drawing above row 103 can change the text screen and the font (`kernel/graphics.md`). No graphics system calls yet. Tested in QEMU only.
- Status: implemented
- Design: `kernel/graphics.md`
