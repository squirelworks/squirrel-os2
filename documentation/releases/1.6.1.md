# 1.6.1 — Desktop: calc in a window

- Date: 2026-10-31
- TODO.md task: **1.6-calc**.
- Changes:
  - **Enter on `calc` in the desktop** runs the calculator in a window. Esc in `calc` closes the window and the desktop is back (`kernel/desktop.asm`, `dk_textwin`).
  - **The text screen can be redirected.** `putc`, `cls` and `scroll_up` write to the address in `txt_base`, which is `0xB8000` by default, and set `txt_dirty`. The desktop points `txt_base` at a page of its own while a program runs in a window.
  - **`kbd_wait_hook`**: `kbd_getscan` calls it, if it is set, while it waits for a key. The desktop uses it to redraw the window when the program has written something.
  - **Console widget** (`wg_console`): shows rows of an 80 × 25 text buffer in a window, following the cursor.
  - The desktop's help line now reads `Up/Down, Enter: open   Esc: shell`.
  - Banner `1.6.1`.
  - Regression checks:
    - `desktop-calc`: `calc> 2 + 2` and `= 4`, read off the window.
    - `desktop-calc-back`: the desktop is there after Esc.
    - `desktop-calc-mem`: the page comes back.
    - `desktop-calc-text`: `systest: PASS` afterwards.
- Known limitations:
  - The window shows 52 of the 80 columns.
  - `edit`, `vedit` and `draw` write to `0xB8000` directly and do not open yet (1.6-edit, 1.6-draw).
  - Tested in QEMU only.
- Status: implemented
- Design: `apps/desktop.md`
