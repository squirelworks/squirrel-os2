# 1.8.2 — objcat

- Date: 2026-10-31
- TODO.md task: **1.8-store**.
- Changes:
  - **`objcat <file>`** (`kernel/object.asm`, `kernel/objects.md`): loads an object file and prints its class and each field by name, text fields as text; then frees the object. Typed alone it prints its `Usage:` line.
  - **The kernel's classes are recorded at boot** (`obj_init`: `Shape`, `Square`, `DesktopObject`, `Program`), so a file saved before a reboot loads again before anything has used its class.
  - The help lists `objs` and `objcat <f>` with the tests; `keys` moved to the next line to keep every line within 80 columns.
  - Banner `1.8.2`.
  - Regression checks: `objcat`, `objcat-boot` (a new boot reads the file earlier checks saved on the same data disk), `objcat-bad`, `objcat-usage`.
- Known limitations:
  - Only the kernel's own classes can be loaded; a program cannot record a class that outlives it.
  - A field that holds an object's address prints as a number.
  - Tested in QEMU only.
- Status: implemented
- Design: `kernel/objects.md`
