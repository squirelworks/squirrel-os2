# 1.8.2 — Objects: objcat across reboot

- Date: 2026-10-31
- TODO.md task: **1.8-store**.
- Changes:
  - **`objcat <file>`** loads an object file and prints its class and fields (`kernel/object.asm`, `kernel/objects.md`). When the class is recorded, fields are named; when it is not (e.g. after a reboot), the class name and field values are still printed from the file.
  - Banner `1.8.2`.
  - Regression check: `obj-persist` (after `objstore`, a new boot runs `objcat objtest.obj` and expects `class Square`, `0: 5`, `1: red`).
- Known limitations:
  - Field names appear only when the class has been recorded in this boot.
  - Tested in QEMU only.
- Status: implemented
- Design: `kernel/objects.md`
