# 0.3.1 — Calculator suite

- Date: 2026-10-14
- Changes:
  - Interactive basic calculator (`run calc`) in `kernel/pm.asm`
    - Integer arithmetic: `+ - * /`
    - Percentage operator (`a % b` → \(a \times b / 100\))
    - Line-oriented input with backspace support
    - Esc returns to command line
  - Scaffolded stubs for scientific (`sci`), graphing (`graph`), matrix (`matrix`), DiffEq/calculus (`diff`), and topology (`topo`) calculators
  - In-memory file table extended to include the new applications
  - Design document: `documentation/apps/calculators.md`
  - Milestone ladder updated in `documentation/plannedmilestones.md`
- Status: basic calculator implemented; advanced calculators scaffolded
- Known limitations:
  - Integer only (no floating point yet)
  - Single binary operator per expression (no chaining or precedence)
  - No previous-result recall (`ans`)
  - No persistent storage
  - Advanced calculators are descriptive stubs only

Build/run: existing protected-mode binary (`kernel/pm.asm` assembled and loaded after the boot sector). Use `run calc` at the prompt.

Next: polish basic calculator (chained ops, `ans`) or proceed to 0.1.1 syscalls / persistent FS.

## Update 2026-10-30 — basic calculator polish

- Rewritten as `kernel/calc.asm`, running as its own process (the old keyboard-ISR calculator mode is gone)
- Operator precedence, parentheses and unary minus; chaining from the previous result (`+ 1`, `* 2`)
- `ans` recall, `clear`, `q`, `hist`
- Percent: `a + b%` / `a - b%` are percentages of `a`; `a * b%`, `a / b%`; binary `a % b` kept
- Errors for syntax (with column), division by zero, overflow and over-long numbers
- History appended to `calc.hist` on the data disk
- Resolves the 0.3.1 limitations "single binary operator", "no ans" and "no persistent storage"
- Design: `documentation/apps/calculators.md`
