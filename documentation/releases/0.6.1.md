# 0.6.1 — Paging and per-process address spaces

- Date: 2026-10-30
- Changes:
  - `kernel/vm.asm`: paging turned on at boot, with an identity map of the first 256 MB (4 KB pages below 4 MB, 4 MB PSE pages above)
  - Every loaded program gets its own page directory, with a private 64 KB program area at `0x30000`. Its pages are freed when the process is reaped.
  - The one-program-at-a-time limit is gone. A program can `SYS_EXEC` another program and wait for it.
  - Program arguments are kept per process slot
  - A CPU exception in a loaded program ends only that program (`Program ended: pid N`); page faults also report the address
  - `ps` shows each process's memory
  - New loader error −6 `Not enough memory to load the program`
  - New programs: `nest` (runs `hello` from inside a program) and `crash` (touches unmapped memory)
  - Regression checks: `vm-nest`, `vm-nest-child`, `vm-crash`, `vm-crash-addr`, `vm-after`, `vm-no-leak`, `vm-ps`
- Status: implemented
- Design: `documentation/kernel/memory.md`
