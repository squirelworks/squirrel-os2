# 0.9.0 — The file browser launches the 1.0 applications

- Date: 2026-10-31
- Changes:
  - Verification only: this already worked since the browser (0.2.3) and the full-screen apps (0.3.2, 0.3.3). Enter on `calc`, `edit`, `vedit` or `draw` in `run files` starts the app, and quitting it returns to the browser with the same entry selected. Esc then leaves the browser for a working shell.
  - Regression checks: `fb-run-edit`, `fb-run-vedit`, `fb-run-draw`, `fb-run-calc` (each starts the app from the browser, quits, and finds the browser again) and `fb-run-back` (shell still works afterwards). Before, only `calc` had a launch check, and `fb-edit` opened a file in the editor rather than starting it.
- Status: verified
