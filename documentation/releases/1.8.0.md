# 1.8.0 — Object files

- Date: 2026-10-31
- TODO.md task: **1.8-format**.
- Changes:
  - **`obj_save` and `obj_load`** (`kernel/object.asm`, `kernel/objects.md`): an object is written as `SQOB`, its class name, its field count and its fields, and read back into a new object of the recorded class with that name.
  - **Classes mark their text fields** in a new `CLS_TEXT` word; those fields are saved as their text and loaded into a kernel text pool. `Square`'s `colour` and `DesktopObject`'s `name` are marked.
  - **`objtest` saves and loads** a square and prints `obj store: PASS`; a file whose class is not recorded is refused.
  - Banner `1.8.0`.
  - Regression check: `objstore`.
- Known limitations:
  - An object file is at most 256 bytes and a text field at most 31 characters; the text pool is 512 bytes and is not freed.
  - A field that holds the address of another object is saved as a number.
  - No command uses the files yet: `objcat` is `1.8-store`.
  - Tested in QEMU only.
- Status: implemented
- Design: `kernel/objects.md`
