# 2.3.0 — Real windows, Program Manager desktop, and everything since 2.1.0

- Date: 2026-11-14
- ROADMAP milestones finished: **2.2** real windows and **2.3** Program Manager / Warp 3 desktop (including **W.1** bevelled controls). Also in this release: the rest of the apps, games and calculator suite; **2.7** long names, FAT and drive objects (diskutil view/check); **2.8** long-mode entry and SMP; **H.1–H.6** modern hardware; **3.0** networking and sound; foreign programs through P.6 (except top-level windows) and P.8 (except a DOS window), plus P.9 LX and P.10 FreeBSD.
- Pull requests: #148–#172 on top of 2.1.0 (notably #151–#172 for the GUI generations and parallel tracks).
- Changes:
  - **Real windows (2.2, #151, #159).** The window manager and desktop draw on a VBE screen (640×480×8 with mode 13h fallback). Overlapping windows move and resize with Warp-style frames (sizing border, title bar, sysmenu / min / max / close), z-order and focus by mouse, minimise to icons, maximise / restore, system menu and keyboard move/size, Alt+Tab / Alt+Esc, and original proportional fonts. Programs open windows through `SYS_GUI` / window events (`progwin`). Checks `winvbe`, `winclip`, `winhit`, `windrag`, `winmin`, `winmenu`, `alttab`, `pfont`, `progwin`.
  - **Program Manager desktop (2.3, #159, #167, #168, #172).** Icon groups from `/desktop` folders, double-click to launch, drag to move, a two-pane File Manager, a kernel text clipboard with field/editor keys and a viewer, Control Panel v1 (colours, mouse, keyboard, date and time; `/desktop/control.cfg`), and Warp-style bevelled widgets as the default (`gfx_bevel` raised / sunken / etched). Checks `pm-*`, `fm-*`, `cbtest` / `clip-*` / `ed-clip-*`, `cp-*`, `bevwidgets`.
  - **Long names, FAT, drive objects (2.7, #162, #171).** SQFS names up to 63 characters; FAT12/16/32 read and write with VFAT names; drive and shredder desktop objects; `diskutil` views and checks FAT volumes (format-FAT in the OS is still open on the 2.7-diskutil box).
  - **64-bit bridge start and modern hardware (2.8, H.1–H.6, #154, #156).** Long-mode entry and return; ACPI MADT CPU discovery; APs started and parked; per-CPU run queues with ring-3 threads on the APs. UEFI loader (IA-32 and x86-64), GOP text console, AHCI, NVMe, xHCI keyboard and USB mass storage. BIOS boot stays the default path.
  - **Networking and sound (3.0 half, #160).** DHCP, DNS (`host`), HTTP/1.1 client (`wget`), network settings program, AC'97 and Intel HDA drivers, mixer, WAV player / recorder / spectrum analyser.
  - **Apps, games, calculators (#148, #152, #155, #157, #161).** Statistics, 3D grapher, hex editor, Write; Sheet, Geometry, CAS, System Monitor, Log Viewer, Disk Utility; Notebook with Nut scripting and `sqmath` v2; Bridge, Checkers and Go; debugger (`SYS_DEBUG`) and Terminal (`SYS_TTY`). A.1–A.7, C.1–C.9 and G.1–G.9 are complete on `main`.
  - **Foreign programs (#149, #153, #163).** `run prog.com` / `.exe` launches dosrun; DOS mode 13h graphics; Linux signals; FreeBSD i386 ELF; OS/2 32-bit LX text mode (`os2run`); Win32 GUI USER32/GDI32 subset, registry emulation and an original DLL loader. Win32 top-level windows as desktop windows (P.6-win32-windows) and a DOS screen in its own window (P.8-dos-window) remain open.
  - **CI and license (#158, #164, #166).** GPL-3.0; GitHub Actions runs `tools/build.sh` and `tools/regress.sh` on every PR.
  - Banner `2.3.0`.
- Regression checks: `tools/regress.sh` has **558** checks (495 at 2.1.0). New ones include the 2.2 window suite, `pm-*` / `fm-*` / `cp-*` / `bevwidgets`, clipboard and FAT/LFN suites, UEFI/AHCI/NVMe/USB, SMP/long-mode, DHCP/DNS/HTTP/audio, and the later foreign-program checks.
- Known limitations:
  - `diskutil` does not yet format FAT volumes in the OS (host `tools/fatimg.py` still makes the images); the TODO **2.7-diskutil** box stays open for that.
  - Win32 GUI programs do not yet own real desktop windows; DOS programs do not yet draw into a window of their own.
  - The 32-bit kernel is not yet permanently in long mode (2.9); PAE/NX (2.8-pae) and the rest of 3.0 (accounts, permissions, services, themes) are next after the foreign-window boxes.
  - Generation 2 desktop (2.5 / 2.6 / W.2–W.6) is not started.
- Build and run: unchanged (`tools/build.sh`, `tools/run.sh`, `guides/getting-started.md`). UEFI images (`uefi.img`) need OVMF or SquirrelBIOS; see `documentation/kernel/hardware.md`.
- Post-merge checks on real hardware: boot USB and hard disk under BIOS and UEFI; Program Manager launch and File Manager copy; Control Panel colour change surviving reboot; a PS/2 or USB mouse on overlapping windows; optional NE2000 / AC97 if present.
- Status: release content ready. **Tagging and publishing are for the owner** (`AGENTS.md` / `HANDOFF.md`). Use Actions → Draft release on the merge commit, then Publish release.
- Design: `kernel/windows.md`, `kernel/widgets.md`, `kernel/graphics.md`, `apps/desktop.md`, `apps/diskutil.md`, `kernel/network.md`, `kernel/audio.md`, `kernel/hardware.md`, `kernel/long-mode.md`, `kernel/smp.md`, `architecture/foreign-compatibility.md`, `architecture/dosrun.md`.
