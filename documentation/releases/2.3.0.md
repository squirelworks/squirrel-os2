# 2.3.0 — Real windows, Program Manager desktop, apps, hardware and more

- Date: 2026-11-14
- ROADMAP milestones finished since 2.1.0: **2.2** real windows (including proportional fonts), **2.3** Program Manager / Warp 3 desktop (icons, groups, File Manager, clipboard, Control Panel v1, bevelled widgets), **W.1** Warp theme (constants, bevels and default 3D controls). Also in this release: most of **2.7** (long names, FAT read/write, drive and shredder objects, diskutil view/check on FAT), **2.8** long-mode entry and SMP, **H.1–H.6** modern hardware, the networking and sound half of **3.0**, the rest of the apps and calculator suite (**A.3–A.7**, **C.1–C.9**), games **G.6** and **G.9** plus GUI fronts, and foreign programs **P.2**, **P.6** (GUI/registry/DLLs), **P.8** (launch and mode 13h), **P.9** (32-bit LX) and **P.10** (FreeBSD).
- Pull requests: #148–#149 and #151–#164, #166–#168, #170–#172 on top of 2.1.0 (#150). (#165 was superseded by #167; #169 is the hand-off tracker.)
- Changes:
  - **Real windows on the VBE framebuffer (2.2, #151, #159).** The window manager and desktop draw at 640×480 8 bpp VBE (mode 13h fallback), with clipped overlapping windows, dirty-rectangle flips, Warp-style frames (title, sizing border, sysmenu / min / max / close), mouse move/resize/raise, minimise to icons and maximise, system menu and Alt+Tab / Alt+Esc, and program windows through syscalls 37–44. Original proportional 9- and 12-pixel fonts (`gfx_drawstr_p`) for title bars, menus and widgets; the 5×7 face stays for consoles and the regress reader.
  - **Program Manager desktop (2.3, #159, #167, #168, #172).** Original 32×32 icons; Program Manager groups with captions, launch, arrange and saved positions; a two-pane File Manager (tree / list, copy/move/rename/mkdir/delete by keys, menu and drag); a 1 KB kernel text clipboard (`SYS_CLIPPUT` / `SYS_CLIPGET`, Ctrl+C/V/X and Ins/Del variants in fields and editors, `clipbrd` viewer); Control Panel v1 (colours, mouse, keyboard, date/time) saved in `/desktop/control.cfg` and applied at boot; Warp bevels on every widget (raised buttons, sunken fields and lists, etched group boxes) through `gfx_bevel` and `theme.inc`.
  - **Apps and calculators (#148, #152, #155, #161).** Statistics, 3D grapher, hex editor, Write, Sheet, Geometry, CAS, System Monitor, Log Viewer, Disk Utility, Notebook with Nut scripting and sqmath v2; syntax highlighting in Notepad; Terminal (`SYS_TTY`) and Debugger (`SYS_DEBUG`, original disassembler, symbols). Completes C.1–C.9 and A.3–A.7 (A.1/A.2 already in 2.1.0).
  - **Games (#157).** Contract Bridge (G.6), Checkers and Go (G.9); graphical front ends for the earlier seven (`run <game> gui`).
  - **Long names, FAT and diskutil (2.7, #162, #171).** SQFS names up to 63 characters; FAT12/16/32 mount/read/write with VFAT; drive and shredder desktop objects; `diskutil` views and checks SQFS long names and FAT volumes on hd0–hd3 (no in-OS FAT format yet).
  - **Long mode and SMP (2.8, #154).** Round-trip long-mode entry (`lmtest`); ACPI MADT discovery; INIT-SIPI-SIPI application processors; per-CPU run queues so APs run ring-3 threads (`cpus`, `smpspin`).
  - **Modern hardware (H.1–H.6, #156).** UEFI loaders (`BOOTX64.EFI` / `BOOTIA32.EFI`, `uefi.img`), GOP console, AHCI (`sd*`), NVMe (`nv*`), xHCI keyboard and USB mass storage (`ud*`).
  - **Networking and sound (3.0 half, #160).** DHCP, DNS (`host` / `dns`), HTTP/`wget`, `netcfg`; AC'97 and HDA behind `SYS_AUDIO`; `wavplay`, `sndrec`, `mixer`, `spectrum`.
  - **Foreign programs (#149, #153, #163).** `run file.com` / MZ starts `dosrun` without naming it; Linux signals; DOS mode 13h; FreeBSD i386 personality; OS/2 32-bit LX text (`os2run`); Win32 GUI subset, registry and DLL loader in `winrun`.
  - **License and CI (#153 then #158, #164, #166).** Project license is GPL-3.0 (same as SquirrelSoft). Every PR runs `build` and `regress` on GitHub Actions; CI installs `python3-numpy` so proportional-font screen reads work.
  - **Docs hand-off (#170).** `HANDOFF.md` and `AGENTS.md` for Cursor/Codex; roadmap status reconciled with `main`.
  - Banner `2.3.0`.
- Regression checks: `tools/regress.sh` has about **790** checks passing on recent `main` gates (495 at 2.1.0). New ones include the `win*`, `pfont`, `pm-*`, `fm-*`, `cb*`/`clip-*`, `cp-*`, `bevwidgets*`, `diskutil-fat*`, `smp-*`, `hw-*`/`uefi-*`, net/audio, debugger/terminal, LFN/FAT, foreign and app self-checks.
- Known limitations:
  - Generation 2 desktop (**2.5** WarpCenter, **2.6** object desktop with drag/drop and notebooks) is not started.
  - **2.7** still has no in-OS FAT `format` (images are made with `tools/fatimg.py`); ROADMAP 2.7 stays open for that.
  - Win32 top-level windows and the DOS screen still use the full-screen `SYS_GUI` surface (**P.6-win32-windows**, **P.8-dos-window**).
  - The 64-bit kernel path (**2.8-pae**, **2.9**) is not done; long-mode entry and SMP are the bridge so far.
  - The rest of **3.0** (accounts, permissions, services, event log, task manager, themes) is open.
  - SQFS directories still hold 64 entries; some test programs live on side images (`progs.img`, `dos.img`, `dev.img`, …).
- Build and run: unchanged for BIOS (`tools/build.sh`, `tools/run.sh`, `guides/getting-started.md`). UEFI: `tools/run.sh --uefi` with `build/uefi.img`. CI: `.github/workflows/ci.yml`.
- Post-merge checks on real hardware: VBE window manager and Program Manager with a real mouse; Control Panel colours and RTC; UEFI / AHCI / NVMe / USB keyboard and stick where available; SMP under `-smp 4` (already in regress); FAT exchange media with a host OS; AC'97 or HDA audio.
- Design: `kernel/windows.md`, `widgets.md`, `icons.md`, `clipboard.md`, `fat.md`, `long-mode.md`, `smp.md`, `hardware.md`, `apps/filemgr.md`, `control.md`, `diskutil.md`, `architecture/foreign-compatibility.md`, `HANDOFF.md`.
