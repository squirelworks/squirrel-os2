# 0.2.3 — File browser

- Date: 2026-10-30
- Changes:
  - `run files`: text-mode file browser (`kernel/browser.asm`)
  - Lists disk files with sizes (ROM files without a disk), tags built-in apps with `[app]`
  - Arrow/page/home/end navigation with a scrolling window
  - Enter launches the app as a child process or views the file; `v` views; `d` deletes after confirmation
  - New built-in `files` entry so the browser appears in its own list
- Status: implemented
- Design: `documentation/apps/files.md`

Regression: `tools/regress.sh` (38 checks).

This completes the 0.2.x storage milestones. Next: application polish (calculator, editors with load/save, draw save) and the program loader (0.3.0).
