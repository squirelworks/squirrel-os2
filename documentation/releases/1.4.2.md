# 1.4.2 — Windows: z-order and focus

- Date: 2026-10-31
- TODO.md task: **1.4-focus**.
- Changes:
  - **Z-order and keyboard focus** (`kernel/wm.asm`). Open windows are kept in a list, bottom first, and `wm_redraw` draws in that order. The top window has the focus and a blue title bar; the others have a dark grey one. New calls `wm_raise`, `wm_cycle` (the bottom window comes to the top), `wm_focus` and `wm_putc` (a character goes to the focused window's text, which its client area shows).
  - **`winfocus`**, a new interactive shell test command. It opens two overlapping windows. Tab swaps the top window and the focus, other keys type into the focused window, and Enter ends. It then reads back which window is drawn on top and prints what each window got.
  - Banner `1.4.2`.
  - Regression checks: `winfocus` (`ab`, Tab, `cd`: One got `cd`, Two got `ab`, One on top), `winfocus-none` (no Tab), `winfocus-text`. With `wm_cycle` not raising the window, `winfocus` prints `Two got "abcd"` and `top: Two`.
- Known limitations: kernel routines and one test command; programs cannot open windows yet. No keys move or resize a window. Tested in QEMU only.
- Status: implemented
- Design: `kernel/windows.md`

This completes milestone 1.4.
