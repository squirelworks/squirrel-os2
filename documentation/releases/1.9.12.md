# 1.9.12 — Devices registered at run time

- Date: 2026-11-01
- TODO.md task: **W.4-devreg**.
- Changes:
  - **`SYS_DEVREG`** (33): a program registers a ready null character device under a new name (up to four such devices). Reads return zeros; writes are discarded.
  - `run drvtest` registers `null`, writes and reads it, prints `drv: PASS`. `devices` then lists `null`.
  - Banner `1.9.12`.
  - Regression checks: `drv`, `drv-devices`.
- Known limitations:
  - Ops are the kernel's null driver, not code loaded from a file. Interrupt-driven I/O and a `/dev` tree stay later.
- Status: implemented
