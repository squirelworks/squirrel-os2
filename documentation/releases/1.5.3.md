# 1.5.3 — Widgets: list

- Date: 2026-10-31
- TODO.md task: **1.5-list**.
- Changes:
  - **List** (`kernel/widget.asm`). `wg_list` adds a column of items with one selected, and `wg_selected` reads the selection. `wg_key` moves the selection with `WK_DOWN` and `WK_UP` (codes 0x19 and 0x18), stopping at the ends. The selected row is drawn as a black bar with white text.
  - Widget records grow to 28 bytes (`WG_SEL`).
  - **`listtest`**, a new interactive shell test command. It opens a window with a label and a list of four names, and passes keys to the widgets until Enter or Esc, with the arrows passed as `WK_UP` and `WK_DOWN`. It checks the selected row's bar and prints `list: <name>`.
  - Banner `1.5.3`.
  - Regression checks: `listtest`, `listtest-end`, `listtest-up`, `listtest-text`. With the selection store taken out of `wg_key`, `listtest` prints `list: Acorn` and the check fails.
- Known limitations: no scrolling (every item must fit in the client area); one key-taking widget per window gets the keys. Kernel routines only. Tested in QEMU only.
- Status: implemented
- Design: `kernel/widgets.md`

This completes milestone 1.5.
