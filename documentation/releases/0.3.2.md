# 0.3.2 — Text editors

- Date: 2026-10-30
- Changes:
  - `edit` and `vedit` rewritten as one full-screen editor engine (`kernel/editor.asm`), running as a process
  - 16 KB buffer with in-place drawing, vertical/horizontal scrolling and a hardware cursor
  - Cursor movement (arrows, Home/End, PgUp/PgDn), insert/overwrite, Delete, Tab
  - Load/save through SQFS: `run edit <file>`, Ctrl+S / F2, save-as prompt, unsaved-changes prompt on quit
  - `vedit`: line numbers, full status (line, column, offset, character in char/hex/decimal, mode, modified flag, size/capacity, name) and a message for every action
  - Shell: `run <app> <arg>` passes a file name to the app; Ctrl key tracking
  - File browser: `e` edits the selected file
  - `cat` ends an unterminated last line with a newline
  - Resolves KB-7 for the editors (no more append-style redraw)
- Status: implemented
- Design: `documentation/apps/editors.md`

Next: drawing program polish (0.3.3) and the program loader (0.3.0).
