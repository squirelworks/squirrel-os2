# 1.7.1 — Objects: instance fields

- Date: 2026-10-31
- TODO.md task: **1.7-fields**.
- Changes:
  - **Instance fields** (`kernel/object.asm`, `kernel/objects.md`): a class names its own fields (`CLS_FIELDS`, a fourth dword in the class record), and they come after all of its parent's, so a subclass keeps the parent's layout. An object holds up to 7 fields after its class pointer.
  - `obj_field` finds a field's index by name through the class chain; `obj_get` and `obj_set` read and write by index and return CF set for an index the class does not have; `obj_nfields` counts a class's fields. `obj_class` refuses a class with more than 7.
  - **`objtest`** also prints `obj fields: PASS`: Shape's `resize` sets `size` (found by name) on a square, Square's `perimeter` reads it as field 0 and gets 20; Square's own `colour` is field 1; a shape has no `colour` and no field 1; and the shape's own `size` is untouched.
  - Banner `1.7.1`.
  - Regression check: `objfields`.
- Known limitations:
  - Fields are dwords; at most 7 per object.
  - Tested in QEMU only.
