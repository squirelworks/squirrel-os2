# 0.4.2 — User programs

- Date: 2026-10-30
- Changes:
  - `programs/ls.asm`: lists the data disk with sizes and a file count; `run ls <text>` shows only names containing the text
  - `programs/cat.asm`: prints one or more files, reports missing ones and keeps going (exit code 1 if any was missing)
  - New syscall `SYS_READDIR` (18): walks the directory one entry per call with a cursor
  - Docs renumbered: the loader is 0.4.0 (flat) and 0.4.1 (ELF32), matching the 0.4.x–0.8.x laundry list; `plannedmilestones.md` gains the 0.4.x–0.8.x ladder
  - Regression checks: `up-ls`, `up-ls-filter`, `up-cat`, `up-cat-missing`
- Status: implemented
- Design: `documentation/kernel/loader.md`, `programs/README.md`

Next: pipes and redirection (0.5.0).
