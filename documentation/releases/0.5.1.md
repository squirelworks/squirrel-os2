# 0.5.1 — Line editing and command history

- Date: 2026-10-30
- Changes:
  - `kernel/lineedit.asm`: the shell line is edited in place (Left/Right, Home/End, Backspace, Delete, insert at the cursor, Esc clears) and redrawn correctly across wrapped rows and scrolling
  - History: Up/Down through the last 16 commands, with the line being typed kept as a draft; blank lines and immediate repeats are skipped
  - History persists in `shell.hist` on the data disk: appended per command, loaded at boot, compacted every 64 lines
  - Kernel image grows from 32 KB to 64 KB: the boot sector reads 128 sectors in two 64-sector reads, the GDT moves into the first 32 KB (real-mode `lgdt`), and a trailing `S2OK` signature is checked at boot
  - `kbd_dispatch` preserves all registers
  - Regression checks: `line-edit`, `line-delete`, `line-esc`, `hist-up`, `hist-draft`, `hist-file`, `hist-reboot`
- Status: implemented
- Design: `documentation/kernel/shell.md`, `documentation/kernel/boot-sector.md`
