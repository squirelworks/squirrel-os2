# 1.6.0 — Desktop: program list

- Date: 2026-10-31
- TODO.md task: **1.6-desktop**.
- Changes:
  - **`desktop`**, a new shell command (new `kernel/desktop.asm`). It shows a window titled `Squirrel-OS/2 Desktop` that lists `files`, `calc`, `edit`, `vedit` and `draw` in a list widget, with a heading and a help line. Up and Down choose a program. Esc closes the desktop and returns to the shell.
  - `wg_getkey` turns scancodes into `wg_key` codes (arrows, Backspace, Esc) for programs in windows.
  - The system still boots to the shell prompt. A `desktop` line in `autoexec.bat` boots into the desktop instead.
  - **`tools/qemu_screen.py` reads graphics text.** The `<gfx>` key dumps the screen and reads text in the kernel's font at any offset and in any colours, printing `gfx: ...` lines. This lets regression checks see windows.
  - Banner `1.6.0`, with `desktop` on the Commands line.
  - Regression checks: `desktop` (the title and all five names, read off the graphics screen), `desktop-quit` (`systest: PASS` after Esc), `gfx-read-list`, and `desktop-boot` / `desktop-boot-quit` (booting into the desktop from `autoexec.bat`).
- Known limitations: Enter does not open a program yet (1.6-calc, 1.6-edit, 1.6-draw). Tested in QEMU only.
- Status: implemented
