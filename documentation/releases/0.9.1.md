# 0.9.1 — Files persist across reboots

- Date: 2026-10-31
- Changes:
  - Verification only: SQFS (0.2.1) writes through to the data disk, so nothing is lost between boots. The regression suite boots QEMU afresh for every check against one shared data disk, so any check that reads what an earlier check wrote is a persistence test.
  - Already covered: `fs-persist`, `hist-reboot`, `ed-reload`, `draw-reload`.
  - New checks: `persist-w` / `persist-r` (a file in a new directory, read back on the next boot), `persist-fb` (a file the editor saved in an earlier boot appears in the browser) and `persist-cd` (the directory and its contents are still there).
- Status: verified
