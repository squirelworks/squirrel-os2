# 1.0.12 — vedit shows control characters

- Date: 2026-10-31
- TODO.md task: **1.0-vedit-controls**, the last 1.0.x task.
- Changes:
  - **Ctrl+T in `vedit`** toggles the control-character display.
    - When it is on, a line end shows as a dim `$`, a tab as `>`, and any other control character as `^`.
    - When it is off, the display is as before.
    - Only the display changes. The buffer, the size in the status line and the cursor column stay the same.
    - In `edit`, Ctrl+T does nothing.
  - **New routine.** `ed_ctlglyph` picks the cell for a control character, and `ed_draw` draws the `$` at each line end.
  - Banner `1.0.12`.
  - Regression checks:
    - `ved-ctl`: line 1 shows `ab$`, and the size is still 5;
    - `ved-ctl-off`: a second Ctrl+T restores `ab`;
    - `ved-ctl-edit`.
  - Checked by hand: a file loaded with a real tab shows `a>b$`.
- Status: implemented
- Design: `apps/editors.md`
