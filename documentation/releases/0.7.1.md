# 0.7.1 — Console and keyboard as devices

- Date: 2026-10-30
- Changes:
  - `kernel/chardev.asm`: `con` (write, through `putc`, so redirection still works) and `kbd` (blocking ASCII read)
  - `SYS_PUTS` writes through `con`; `SYS_GETC` reads through `kbd` when input is not redirected
  - The key-to-ASCII loop moved from `sys_getc` to `kbd_getchar`
- Status: implemented
- Design: `documentation/kernel/drivers.md`
