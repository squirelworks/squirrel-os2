# 1.3.3 — graph plots a function

- Date: 2026-10-31
- TODO.md task: **1.3-graph** (last of milestone 1.3, which is now complete).
- Changes:
  - **`graph` is no longer a scaffold.** New `kernel/graph.asm`: at the `graph>` prompt, `y = <f(x)>` (or just `<f(x)>`) plots `f` in 320 × 200 graphics for x and y from −10 to 10, with axes, the function as a label and the range. `f` is evaluated by the `sci` evaluator, as in `diff`, once per screen column; neighbouring points are joined with `gfx_line`, and undefined points break the curve. Any key returns to the text screen and a summary line: `Plotted y = x for x from -10 to 10: 320 points, 319 on screen`. Syntax errors are reported before the screen changes.
  - **The text screen survives graphics.** `gfx_mode13` saves the 4000 bytes of text and the 8 KB font from plane 2 in three pages from `pg_alloc`; `gfx_text` restores them and frees the pages (`kernel/graphics.md`).
  - The banner lists `graph` among the apps; only `topo` is still planned (and is still a scaffold). `cat graph` shows the new help.
  - Banner `1.3.3`.
  - Regression checks: `graph` (the prompt line is still on screen afterwards, and the summary line), `graph-domain` (`sqrt(x)`: 160 points), `graph-syntax`, `graph-mem` (the three pages come back), `topo-stub`; `ver-planned` now expects `(planned: topo)`.
- Known limitations: one function, fixed window, no zoom or pan. Tested in QEMU only.
- Status: implemented
- Design: `apps/calculators.md`, `kernel/graphics.md`
