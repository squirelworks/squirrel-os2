# 1.5.0 — Widgets: label

- Date: 2026-10-31
- TODO.md task: **1.5-label**.
- Changes:
  - **Widgets** (new `kernel/widget.asm`). A table of up to 16 widgets, each belonging to a window and placed in its client area. `wm_draw` draws a window's widgets after its client area, cut to that area. `wm_close` drops them (`wg_drop`).
  - **Label**, the first widget: `wg_label` adds one line of text to a window.
  - **`labeltest`**, a new shell test command. It adds a label to a window and reads back an ink pixel and a background pixel of the label. It then closes the window, opens a new one in the same slot, and checks that the label is gone. It prints `label: PASS` or `FAIL`.
  - Banner `1.5.0`.
  - Regression checks: `labeltest`; `labeltest-text` (`systest` after `labeltest`). Without the call that draws widgets, or without `wg_drop`, `labeltest` prints FAIL.
- Known limitations: kernel routines only; one font size; a label cannot be changed once added (remove the window to remove it). Tested in QEMU only.
- Status: implemented
- Design: `kernel/widgets.md`
