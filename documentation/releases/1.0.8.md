# 1.0.8 — Numerical integrals in diff

- Date: 2026-10-31
- TODO.md task: **1.0-diff-integ**.
- Changes:
  - **New command.** `i <f(x)> from <a> to <b>` prints the integral. It uses the composite Simpson rule on 1000 panels, on the same `sci` evaluator that the derivative uses.
  - **Shared parsing.** `diff_cut` splits a command at the words `at`, `from` and `to`, and `diff_value` evaluates a bound. The derivative now uses both, too.
  - `cat diff` and the `diff` help list the new command.
  - Banner `1.0.8`.
  - Regression checks:
    - `diff-int1`: the constant 1 from 0 to 2 is exactly `= 2`;
    - `diff-intsin`, `diff-intexp`, `diff-intrev`, `diff-noto`.
- Status: implemented
