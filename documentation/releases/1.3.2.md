# 1.3.2 — Text in graphics mode

- Date: 2026-10-31
- TODO.md task: **1.3-text**.
- Changes:
  - **An original 5 × 7 font** for printable ASCII (0x20–0x7E). The glyphs are drawn as text in `tools/font5x7.txt`; new `tools/mkfont.py` builds `kernel/font.inc` from it, and `tools/regress.sh` runs `mkfont.py --check` next to `mkstrings.py --check`.
  - `gfx_drawchar` draws one character in a 6 × 8 cell (ink in `gfx_colour`, background in `gfx_bg`); `gfx_drawstr` draws a zero-terminated string (`kernel/gfx.asm`).
  - **`gfxtext`**, a new shell test command: draws `Squirrel-OS/2` in graphics mode, reads back ink and background pixels of the first glyph, the spacing column and a pixel outside the string, returns to text mode and prints `gfxtext: PASS` or `FAIL`.
  - Banner `1.3.2`.
  - Regression checks: `gfxtext`; `gfxtext-text` (`systest` after `gfxtext`). Without the drawing, `gfxtext` prints FAIL.
- Known limitations: one size, no scaling; the same rows-103-and-below rule as the other primitives (`kernel/graphics.md`). Tested in QEMU only.
- Status: implemented
- Design: `kernel/graphics.md`
