# 1.5.2 — Widgets: edit field

- Date: 2026-10-31
- TODO.md task: **1.5-field**.
- Changes:
  - **Edit field** (`kernel/widget.asm`). `wg_field` puts a one-line field over a buffer the caller owns, with a most-characters limit. `wg_key` now gives a key to the first button or field of the focused window. A field appends printable characters while there is room, and Backspace (8) deletes the last one. The field is drawn as a box as wide as its limit, with the text and an underline cursor.
  - Buttons and fields share the box drawing.
  - **`fieldtest`**, a new interactive shell test command. It opens a window with a label and a 16-character field and passes keys to the widgets until Enter or Esc. It prints `field: PASS "<text>"` with what the buffer holds.
  - Banner `1.5.2`.
  - Regression checks: `fieldtest` (typing and Backspace), `fieldtest-full` (the limit), `fieldtest-text`. With the store taken out of `wg_key`, `fieldtest` prints `field: PASS ""` and the check fails.
- Known limitations: no cursor movement inside the text (Left, Right, Home, End); one field per window takes the keys. Kernel routines only. Tested in QEMU only.
- Status: implemented
