# 1.9.3 — Network layer and loopback

- Date: 2026-11-01
- TODO.md task: **2.0-loop**.
- Changes:
  - **A network layer** (`kernel/net.asm`, `kernel/network.md`): interfaces with a transmit routine and a receive queue of 8 frames; `net_send`, `net_rxq`, `net_recv`. A queued frame lives in its own page, taken when it is queued and given back when it is read.
  - **A loopback interface** `lo`: what is sent on it comes back in order.
  - **`nettest`** sends three frames of 60, 1514 and 1 bytes on loopback and reads them back; an empty queue and frames of 0 or 1515 bytes are refused. It prints `net: PASS`.
  - Banner `1.9.3`.
  - Regression checks: `nettest`, `nettest-mem` (free memory is the same after two runs).
- Known limitations:
  - No network card yet (`2.0-nic`), and no protocols: frames are raw bytes.
  - The queue is per interface and is not locked; only the kernel uses it so far.
  - Tested in QEMU only.
- Status: implemented
- Design: `kernel/network.md`
