# 1.8.3 — Desktop entries on disk

- Date: 2026-10-31
- TODO.md task: **1.8-desktop**.
- Changes:
  - **The desktop keeps its entries in `/desktop`** (`kernel/desktop.asm`, `apps/desktop.md`): the first time, it saves one `Program` object file per entry (`files.obj`, `calc.obj`, `edit.obj`, `vedit.obj`, `draw.obj`); each time it starts it loads the files that are there and lists them. Removing a file removes its entry.
  - **A Program's `entry` is the program's name** as a text field, so the files do not hold kernel addresses; `open` looks the name up.
  - Regression: a `check_none` helper (one text must not be on the screen, another must), and checks `dk-store`, `dk-store-cat`, `dk-store-rm`, `dk-store-left`, `dk-store-open` on a data disk of their own.
  - Banner `1.8.3`.
- Known limitations:
  - Only the five default names are looked for: a new file put in `/desktop` is not listed, and the order is fixed.
  - With every file removed, the desktop falls back to the built-in entries rather than an empty list.
  - Tested in QEMU only.
- Status: implemented
- Design: `apps/desktop.md`
