# 0.3.4 — Scientific and matrix calculators

- Date: 2026-10-30
- Changes:
  - FPU enabled at boot (`fpu_init`: CR0.MP/NE set, EM/TS clear, `fninit`, exceptions masked)
  - `sci` (`kernel/sci.asm`): floating-point expressions with `+ - * / ^`, parentheses, `pi`, `e`, `ans`, `sin cos tan asin acos atan sqrt ln log exp abs`, `deg`/`rad` mode, 10-digit output with scientific notation for very large and very small values, and syntax, division, overflow and domain errors
  - `matrix` (`kernel/matrix.asm`): variables A–Z and `ans` up to 6×6, literals `[1 2; 3 4]`, `+ - *`, scalar multiples, negation, `det`, `trans`, `inv`, `list` and `clear`
  - Built-in file entries for `sci` and `matrix` now show their help text instead of the scaffold notice
  - `tools/qemu_screen.py` can type `^ [ ]`
  - Regression checks: ten `sci-*` and six `mx-*`; `slot-reuse` now launches `topo`, since `sci` is interactive
- Status: implemented
- Design: `documentation/apps/calculators.md`
- Version note: numbered 0.3.4 to follow 0.3.3, as the 0.3.1 calculator milestone was already used by `calc`

Next: persistence across reboot and the stability pass (0.9.1–0.9.2).
