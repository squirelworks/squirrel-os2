# 1.4.0 — Windows: create and close

- Date: 2026-10-31
- TODO.md task: **1.4-create**.
- Changes:
  - **A window manager** (new `kernel/wm.asm`): a table of up to 4 windows; `wm_create` and `wm_close`; `wm_redraw` paints a desktop and each open window with its frame, title bar, title and client area, using the 1.3 graphics primitives.
  - **`wintest`**, a new shell test command: creates a window, reads back a frame pixel and a title pixel, closes the window and reads the frame pixel again (now the desktop), returns to text mode and prints `win: PASS` or `FAIL`.
  - Banner `1.4.0`.
  - Regression checks: `wintest`; `wintest-text` (`systest` after `wintest`).
- Known limitations: kernel routines only, no system call for programs yet; windows cannot be moved, resized or focused yet (later 1.4 tasks). Tested in QEMU only.
- Status: implemented
- Design: `kernel/windows.md`
