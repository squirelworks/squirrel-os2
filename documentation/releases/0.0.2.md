# 0.0.2 — Native PIT timer

- Date: 2026-10-14
- Artifact: `kernel/boot.asm`
- Changes:
  - Replaced firmware `int 0x1A` delays with a native PIT channel 0 interrupt (IRQ0) at ~100 Hz
  - Tick counter drives the ~15 s beep interval
  - Light jitter taken from a free-running seed
  - PC speaker still driven via PIT channel 2
  - External behavior unchanged: `UwU` on screen + periodic beep
- Limitations: still real-mode boot sector; no protected mode yet
- Status: implemented
