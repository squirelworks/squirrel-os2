# 0.7.0 — Driver registration table

- Date: 2026-10-30
- Changes:
  - `kernel/dev.asm`: device descriptors (name, type, probe, read, write, unit, flags, size), `dev_register` with probing, `dev_find`, and typed dispatch (`dev_read`/`dev_write` for character devices, `dev_bread`/`dev_bwrite` for block devices)
  - Syscalls `SYS_DEVFIND` (22), `SYS_DEVREAD` (23), `SYS_DEVWRITE` (24); read-only devices refuse program writes
  - Shell: `devices` lists the table
  - New program `devtest`
- Status: implemented
- Design: `documentation/kernel/drivers.md`

Released together with 0.7.1 and 0.7.2, which register the first devices.
