# 0.9.3 — Release readiness

- Date: 2026-10-31
- Why: before calling a version 1.0, I booted the system the ways a new user might: one long session with a reboot, other memory sizes and CPUs, a floppy image, and a second emulator (Bochs). This release fixes what that turned up and makes building and running a one-liner.
- Changes:
  - **Floppy boot (KB-11).** The boot sector falls back to cylinder/head/sector reads, with retries, for floppies and for firmware without extended reads. `build/floppy.img` boots.
  - **Memory map after a floppy boot (KB-12).** The kernel clears ES before asking the BIOS for the memory map.
  - **CPU check (KB-13).** A CPU without CPUID, an FPU or 4 MB pages gets a clear message instead of a silent crash.
  - **Version (KB-14).** The banner says 0.9.3, and `banner_rest` in `pm.asm` is the one place the version lives.
  - **Stub apps.** `graph`, `diff` and `topo` are listed as planned instead of next to the working apps.
  - **Calc history (KB-15).** `calc` keeps its history in `/calc.hist` wherever it runs.
  - **Scripts.**
    - `tools/build.sh` builds `build/os.img`, `build/floppy.img` and a data disk with the sample programs.
    - `tools/run.sh` starts QEMU.
    - `tools/bochs_smoke.sh` boots the image in Bochs, runs `systest`, `fstest`, `proctest`, `memtest` and `calc` through `autoexec.bat`, reboots, and checks the files persisted.
  - `tools/qemu_screen.py` takes `--floppy`, and extra QEMU options in `QEMU_EXTRA`.
  - `guides/getting-started.md` covers the scripts, Bochs, VirtualBox and real hardware.
  - Regression checks: `ver-banner`, `ver-planned`, `calc-hist-root`, `floppy-boot`, `floppy-data`, `floppy-e820`, `cpu-nopse`, `cpu-nofpu`.
- Localization: the two new messages (boot sector and CPU check) are English only. They print before the kernel's string table and `lang` exist, and the boot sector has no room for a table.
- Tested on:
  - QEMU 8.2 (TCG) with 4 MB to 128 MB of memory, booting from hard disk and floppy, with and without a data disk.
  - Bochs 2.7 with its legacy BIOS (64 MB). Bochs's newer BIOS image crashes during its own start-up in this setup, before any of our code runs.
  - Not yet on VirtualBox, VMware or real hardware.
- Status: implemented
