# 0.0.3 — Protected-mode transition

- Date: 2026-10-14
- Artifacts:
  - `kernel/boot.asm` — loads second stage
  - `kernel/pm.asm` — enters 32-bit protected mode
- Changes:
  - Boot sector loads a second stage from disk
  - Second stage builds a minimal GDT (null, code, data)
  - Sets PE bit in CR0 and far-jumps into 32-bit code
  - Reloads segment registers and stack
  - Writes `UwU` from protected mode
  - Issues one beep (timing interrupt not yet re-established in PM)
- Limitations:
  - No IDT / IRQ handling yet
  - Periodic beep from 0.0.2 not carried forward
  - Still uses firmware for disk load and initial video mode
- Status: implemented

Next: re-introduce native timer under a protected-mode IDT.
