# 0.2.1 / 0.2.2 — On-disk file system (SQFS)

- Date: 2026-10-30
- Changes:
  - SQFS on the data disk: superblock, 64-entry flat directory, contiguous extents with first-fit allocation and move-on-grow (`kernel/fs.asm`)
  - Blank data disks are formatted and seeded with the built-in files at boot; foreign disks are left alone
  - API and syscalls 10–16: open/read/write/close, create, delete, rename (flags `O_CREATE`, `O_TRUNC`, `O_APPEND`)
  - Shell: `ls` (with sizes) and `cat` now read the disk; new `put`, `mk`, `rm`, `mv`, `format`, `fstest`
  - Files survive a reboot (verified by the regression run across separate QEMU boots)
  - ROM fallback for `ls`/`cat` when no data disk is attached; fixed the old ROM lookup's loop-counter bug
  - Boot sector now loads a 32 KB kernel with the BIOS extended read (int 0x13 AH=0x42)
  - `systest` exercises the file syscalls when a disk is mounted
- Status: implemented
- Known limitations: see `kernel/filesystem.md`
- Design: `documentation/kernel/filesystem.md`

Build/run: image is now 1 + 64 sectors; commands unchanged. Regression: `tools/regress.sh`.

Next: file browser that can launch apps (0.2.3).
