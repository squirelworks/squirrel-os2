# 1.0.7 — Numerical derivatives in diff

- Date: 2026-10-31
- TODO.md task: **1.0-diff-deriv**.
- Changes:
  - **`diff` is no longer a scaffold.** New `kernel/diff.asm`. `d <f(x)> at <x0>` prints f'(x0), computed by a central difference on the `sci` evaluator. There are no symbolic rules and no second math library.
  - **`sci` has a variable.** `sci_primary` accepts `x`, but only while `diff` evaluates a function (`sci_xok`). In `sci` itself, `x` is still a syntax error.
  - `diff` always uses radians, and puts back the `sci` angle mode afterwards.
  - `cat diff` shows the new help. The banner lists `diff` among the apps, and only `graph` and `topo` remain planned.
  - Banner `1.0.7`.
  - Regression checks:
    - `diff-sin`: `d sin(x) at 0` prints exactly `= 1`;
    - `diff-poly`, `diff-exp`, `diff-rad`, `diff-domain`, `diff-noat`, `diff-exit`;
    - `sci-nox`;
    - `ver-planned` is updated.
