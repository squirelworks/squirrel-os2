# 1.0.10 — Euler ODE stepper in diff

- Date: 2026-10-31
- TODO.md task: **1.0-diff-ode**.
- Changes:
  - **New command.** `euler <f(x,y)> from <x0> to <x1> y0 <y0> step <h>` solves y′ = f(x, y) by Euler's method and prints y(x1).
    - The step is adjusted so that a whole number of steps lands exactly on x1.
    - `step` must be greater than 0, and at most 100000 steps are allowed.
  - **`sci` has a second variable.** `sci_primary` accepts `y` when `sci_xok` is 2. `diff` sets that only inside `euler`, so `y` stays a syntax error in `d`, `i` and `sci`.
  - The `diff` help and `cat diff` list the command.
  - Banner `1.0.10`, the tenth 1.0.x patch.
  - Regression checks:
    - `diff-euler1`: one step of y′ = y from y(0) = 1 with h = 0.1 gives exactly `= 1.1`, the acceptance check;
    - `diff-euler`: 1000 steps give 2.716923932, which is (1.001)^1000;
    - `diff-eulerxy`, `diff-eulerh`, `diff-noy`.
- Status: implemented
