# 0.2.0 — Block device driver

- Date: 2026-10-30
- Changes:
  - ATA PIO driver, primary channel, LBA28, polled (`kernel/ata.asm`)
  - IDENTIFY probe of master (boot disk) and slave (data disk) at boot
  - `ata_read` / `ata_write` (with cache flush), bounds-checked against drive size
  - Syscalls `bread` (8) and `bwrite` (9, data disk only)
  - Shell: `disk` (drive list), `blktest` (write/read/compare round trip)
  - `systest` checks the boot signature through `bread`
  - Kernel scratch area at `0x20000` and a documented memory map
  - `tools/qemu_screen.py --disk`; `tools/regress.sh` attaches a fresh 1 MB data disk (24 checks)
- Status: implemented
- Known limitations: single sector per call, no IRQ/DMA, primary channel only
- Design: `documentation/kernel/block-device.md`, `documentation/kernel/memory-map.md`

Run with a data disk:

```bash
qemu-system-i386 -drive format=raw,file=os.img,index=0,media=disk \
                 -drive format=raw,file=data.img,index=1,media=disk
```
