# 0.6.2 — Program heaps

- Date: 2026-10-30
- Changes:
  - `SYS_SBRK` (21): each program has a heap at `0x40000000` of up to 4 MB that grows and shrinks a page at a time. New memory reads as zero; memory given back is unmapped at once.
  - Heap pages are freed when the program's process is reaped, even if it never gave them back
  - `sqx.inc` names `SYS_PALLOC`, `SYS_PFREE` and `SYS_SBRK`
  - New program `heap` (`run heap`, `run heap after`, `run heap keep`)
  - Regression checks: `heap`, `heap-limit-after`, `heap-keep-leak`
- Status: implemented
- Not done: stack growth (stacks stay 8 KB until user mode, see `kernel/memory.md`)
- Design: `documentation/kernel/memory.md`
