# 1.9.7 — UDP

- Date: 2026-11-01
- TODO.md task: **2.0-udp**.
- Changes:
  - **UDP** (`kernel/udp.asm`, `kernel/network.md`). Four sockets, 256 bytes in a datagram, four datagrams waiting. A port belongs to one process.
  - **`net_sendto` and `net_recvfrom`** (system calls 30 and 31). A block in `ebx` names the address, the ports and the bytes. −1 means the port is already bound. −2 means nothing arrived.
  - **`udptest`** sends `udpok` to itself on 127.0.0.1 and reads it back, then a second process is refused the same port. It prints `udp: PASS`.
  - Banner `1.9.7`.
  - Regression check: `udp`.
- Known limitations:
  - No TCP yet (`2.0-tcp`).
  - 256 bytes and four sockets. Tested in QEMU only.
- Status: implemented
- Design: `kernel/network.md`
