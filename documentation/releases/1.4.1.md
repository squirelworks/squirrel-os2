# 1.4.1 — Windows: move and resize

- Date: 2026-10-31
- TODO.md task: **1.4-move-resize**.
- Changes:
  - `wm_move` and `wm_resize` (`kernel/wm.asm`). Both check the new place or size with the same rule as `wm_create` (at least 16 × 14, wholly on the screen) and return CF, leaving the window unchanged, when it fails. `wm_create`, `wm_move`, `wm_resize` and `wm_close` share that check and the id lookup.
  - **`winmove`**, a new shell test command: moves a window, then resizes it, reading back the old and the new frame pixels after each step; then checks that a move off the screen and a too-small size are refused. Prints `winmove: PASS` or `FAIL`.
  - Banner `1.4.1`.
  - Regression checks: `winmove`; `winmove-text` (`systest` after `winmove`). With the stores in `wm_move` or in `wm_resize` taken out, `winmove` prints FAIL.
- Known limitations: kernel routines only; no keys move a window yet, and there is one window at a time in the tests (focus and z-order are **1.4-focus**). Tested in QEMU only.
- Status: implemented
- Design: `kernel/windows.md`
