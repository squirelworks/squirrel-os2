# 1.9.1 — Pick up, move and drop

- Date: 2026-11-01
- TODO.md task: **1.9-move**.
- Changes:
  - **`m` picks up** the chosen desktop object, and the help row names it (`Held: calc  p: drop  Esc: back`). It stays held while Enter and Backspace move between folders (`kernel/desktop.asm`, `apps/desktop.md`).
  - **`p` drops it** into the folder shown: its `in` field becomes that folder's name, and its file in `/desktop` is saved, so the move outlives a reboot.
  - **Esc while holding** puts it back and writes nothing. A folder can only be dropped at the top level.
  - Banner `1.9.1`.
  - Regression checks: `dk-hold`, `dk-hold-esc`, `dk-move`, `dk-move-top`, `dk-move-cat`, `dk-move-open`, `dk-move-fold`.
- Known limitations:
  - The held object stays in the list it came from until it is dropped.
  - Without a data disk, a move lasts until the desktop closes.
  - Tested in QEMU only.
- Status: implemented
- Design: `apps/desktop.md`
