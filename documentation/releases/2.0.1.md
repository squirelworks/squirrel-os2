# 2.0.1 — Mouse on IRQ 12, pointer without a trail

- Date: 2026-11-04
- TODO.md tasks: **2.0.1-irq12**, **2.0.1-saveunder**, **2.0.1-sign** (the 2.0.x clean-up in `ROADMAP.md`).
- Changes:
  - The PS/2 mouse is interrupt-driven: `mouse_isr` on IRQ 12 (vector `0x2C`) reads each auxiliary byte. The kernel unmasks the cascade and IRQ 12 only when the mouse answered at boot.
  - `kbd_isr` hands an auxiliary byte that arrives on IRQ 1 to the mouse instead of the keyboard ring.
  - Fixes **KB-18**: after the mouse moved or clicked in the text shell, the keyboard stopped, because the mouse's byte stayed in the controller and blocked the keys behind it.
  - `mousetest` no longer polls, so its PASS shows the interrupt path works.
  - Packets are decoded as 9-bit motion: the sign bits in byte 0 are used, so fast moves (more than 127 counts) no longer go the wrong way, and packets with an overflow bit set have their motion dropped (`mouse_decode`). `mousetest` first prints `decode: PASS` from fixed packets.
  - The desktop pointer keeps the pixels under it and puts them back when it moves (`ptr_show` / `ptr_hide`), so it no longer leaves a trail across the program list. `wm_redraw` discards the saved pixels. New shell test `ptrtest` prints `ptr: PASS`.
  - Banner `2.0.1`.
  - Regression checks: `mouse-still`, `mouse-shell`, `mouse-calc`, `ptrtest`, `ptr-trail`, `mouse-decode` (plus `mousetest`, `ver-banner`, `lang-banner`).
- Known limitations:
  - Clicks ignore list scrolling. That is a 2.0.2 box.
- Build and run: unchanged (`tools/build.sh`, `tools/run.sh`, `guides/getting-started.md`).
- Known bugs: none open (`knownbugs.md`; KB-18 resolved here).
- Post-merge checks on real hardware: a PS/2 mouse (or USB mouse with legacy emulation) moved in the text shell does not stop the keyboard; the desktop pointer leaves no trail.
- Status: release content ready on `main` (all three 2.0.1 boxes). **Tagging is for the owner**: annotated tag `v2.0.1`, with `os.img`, `floppy.img`, `data.img`, `cd.iso` and `SHA256SUMS` attached to the GitHub Release.
