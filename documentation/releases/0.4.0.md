# 0.4.0 / 0.4.1 — Program loader (flat binaries and ELF32)

- Date: 2026-10-30
- Changes:
  - `kernel/loader.asm`: loads a program file from SQFS into the 64 KB program area (`0x30000`) and starts it as a process
  - Formats: SQX flat binary (16-byte header with entry and memory size) and static ELF32 (`PT_LOAD` segments, bss zeroed)
  - `run <file> [text]` falls back to the disk when the name is not a built-in app; the program gets the rest of the line as its argument
  - New syscall `SYS_EXEC` (17)
  - File browser: Enter on a program file runs it
  - Host tool `tools/sqfs.py`: format, ls, put, get and rm on SQFS disk images
  - Sample programs in `programs/`: `hello`, `wc`, `elfhello`, plus `sqx.inc`
  - Regression checks: `ld-sqx`, `ld-arg`, `ld-wc`, `ld-elf`, `ld-notprog`, `ld-big`, `ld-missing`, `ld-again`, `ld-browser`, `ld-host-ls`
- Status: implemented
- Numbering: first planned as 0.3.0; renumbered to 0.4.0 (flat) and 0.4.1 (ELF32) to match the 0.4.x–0.8.x laundry list
- Design: `documentation/kernel/loader.md`

Next: user programs `cat` and `ls` (0.4.2).
