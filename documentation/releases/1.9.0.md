# 1.9.0 — Desktop folders

- Date: 2026-11-01
- TODO.md task: **1.9-folder**.
- Changes:
  - **Folders** (`kernel/desktop.asm`, `apps/desktop.md`): a `Folder` class under `DesktopObject`, and a text field `in` on `DesktopObject` (the folder that holds an object; empty for the top level). The desktop lists the objects in the folder being shown; Enter on a folder shows its contents and titles the window with its name; Backspace goes back to the top level.
  - The first time, `/desktop` also gets an empty folder `Tools` (`Tools.obj`).
  - 1.8's desktop files have one field fewer and are refused; when none load, the defaults are written again.
  - The help row reads `Enter: open  Bksp: up  Esc: shell`.
  - Banner `1.9.0`.
  - Regression checks: `dk-folder`, `dk-folder-open`, `dk-folder-back`, `dk-folder-cat`, `dk-folder-quit`.
- Known limitations:
  - Folders do not nest in the list: Backspace always returns to the top level, and the files are still the six default names.
  - Moving into `Tools` is 1.9.1.
  - Upgrading a 1.8 disk brings back entries whose files had been removed.
  - Tested in QEMU only.
- Status: implemented
- Design: `apps/desktop.md`
