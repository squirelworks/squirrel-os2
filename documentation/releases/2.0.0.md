# 2.0.0 — Warp-style system

- Date: 2026-11-01
- TODO.md task: **2.0.0**.
- Goal (from `ROADMAP.md`): the first release that can honestly be called Warp-like.
  Preemptive threads, the windowing system, the object desktop, the hierarchical
  file system with a graphical browser, the 1.0 applications as desktop objects,
  a native shell, and basic networking. Original code. No classic OS/2 ABI.
- What 2.0.0 is: the 1.9.12 system, tagged. This release adds no features of its
  own. Every 2.0 prerequisite in `ROADMAP.md` is already on `main` (1.1–1.9,
  networking through TCP, and the Warp-gap boxes 1.9.9–1.9.12). Its changes are:
  - **Version.** The banner says `Squirrel-OS/2 2.0.0`; `ver-banner` and
    `lang-banner` expect it.
  - **Documentation.** Release note, PROCESS table and next-planned line,
    README indexes, `plannedmilestones.md`, and a `specifications.md` section.
- Prerequisites (already shipped):
  - Preemption and threads (`1.1.0`, `1.1.1`)
  - Message queues and key events (`1.2.0`, `1.2.1`)
  - Graphics, windows, widgets, desktop (`1.3`–`1.6`)
  - Object model, installer, object files (`1.7`–`1.8`)
  - Desktop folders, move/drop, rename/delete (`1.9.0`–`1.9.2`)
  - Networking: loopback, NE2000, ARP, IPv4/ICMP, UDP, TCP (`1.9.3`–`1.9.8`)
  - Warp gaps: priority, mouse, `ifconfig`, run-time devices (`1.9.9`–`1.9.12`)
- How to build and run: `tools/build.sh`, then `tools/run.sh`. See
  `guides/getting-started.md`.
- Known limitations: `specifications.md` through 1.9.12. Modern hardware
  (UEFI, AHCI, NVMe, USB — H.1–H.6) and foreign personalities stay later.
- Known bugs: none open (`knownbugs.md`).
- Next: modern hardware H.1–H.6 in `TODO.md` / `ROADMAP.md`; then 2.x / 3.0
  vision in `plannedmilestones.md`.
- Status: release content ready. **Tagging is for the owner** (`TODO.md`: ask
  before tagging). History uses annotated tags such as `v1.0.0`.
