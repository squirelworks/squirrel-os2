# 1.0.9 — Search in the editors

- Date: 2026-10-31
- TODO.md task: **1.0-edit-search**.
- Changes:
  - **Ctrl+F** in `edit` and `vedit` asks for text on the message line, which may contain spaces.
    - The search starts after the cursor, wraps around, and is case-sensitive.
    - It moves the cursor to the match.
    - It reports `Found <text> at line L, column C`, or `Not found: <text>`.
  - **F3** repeats the last search.
  - `ed_prompt` accepts spaces when its caller allows them. File names still may not contain them.
  - The `edit` key reminder now names Ctrl+F.
  - Banner `1.0.9`.
  - Regression checks:
    - `ed-find`: the message line for `zebra`;
    - `ed-find-at`: a key typed after the find lands at `zebra`;
    - `ed-find-again`: F3 twice, wrapping;
    - `ed-find-space`: `vedit`, text with a space;
    - `ed-find-none`.
- Status: implemented
- Design: `apps/editors.md`
