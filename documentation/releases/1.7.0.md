# 1.7.0 — Objects: classes and messages

- Date: 2026-10-31
- TODO.md task: **1.7-class**.
- Changes:
  - **Classes and messages** (`kernel/object.asm`, `kernel/objects.md`): a class has a name, a parent and a method table of selector names and handlers. `obj_class` records a class, `obj_new` makes an object, and `obj_send` finds the method in the object's class or its parents and runs it with the object as self.
  - **`objtest`**: `Square` under `Shape` inherits `name` and `describe` and overrides `area`; `describe` sends `area` to self and gets Square's; an unknown selector returns an error. It prints `obj: PASS`.
  - Banner `1.7.0`; `objtest` is listed with the other tests.
  - Regression checks: `objtest`, `objtest-text` (the shell is fine after two runs).
- Known limitations:
  - No instance fields, no freeing routine and no listing yet (`1.7-fields`, `1.7-objs`).
  - Classes are records in kernel data; programs cannot define their own yet.
  - Tested in QEMU only.
