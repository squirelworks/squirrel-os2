# 1.9.2 — Rename and delete on the desktop

- Date: 2026-11-01
- TODO.md task: **1.9-actions**.
- Changes:
  - **`r` renames** the chosen object in a `Rename` window with a field widget. The new name is saved to the object's file and listed. A renamed folder's contents follow it (`kernel/desktop.asm`, `apps/desktop.md`).
  - **Delete removes** the chosen object and its file after a `y` on the help row. A folder that is not empty is refused.
  - `wg_getkey` returns `WK_DEL` (0x7F) for Delete (`kernel/widget.asm`).
  - Banner `1.9.2`.
  - Regression checks: `dk-rename-win`, `dk-rename`, `dk-rename-esc`, `dk-delete-ask`, `dk-delete-no`, `dk-delete`, `dk-delete-full`.
- Known limitations:
  - A renamed object's file keeps its old name.
  - Deleting every file brings the defaults back at the next desktop.
  - The list's selection returns to the first entry after a rename.
  - Tested in QEMU only.
- Status: implemented
- Design: `apps/desktop.md`
