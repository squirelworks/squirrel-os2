- Changes:
  - **`objs`** shell command (`kernel/object.asm`, `kernel/objects.md`): lists the recorded classes, each with ` < ` and its parent, then the live objects as `slot: class`, then how many are live.
  - **`obj_free`** gives an object's slot back. It refuses (CF set) an address that is not a slot in the object table, or a slot that is already free.
  - `objtest` frees its two objects with `obj_free`, and checks that freeing one of them a second time is refused.
  - Banner `1.7.3`; `objs` is listed on the banner's test line.
  - Regression checks: `objs-empty`, `objs-tree`, `objtest-mem`.
- Known limitations:
  - Only the kernel's own classes exist so far (objtest's `Shape` and `Square`); the desktop's come with **1.7-desktop**.
