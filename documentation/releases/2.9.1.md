# 2.9.1 — 64-bit syscall ABI (`2.9-syscall64`)

**Date:** 2026-11-16  
**Mark:** M7 in `TO_3.0.0.md`  
**Lane:** `-b55f`

## Summary

ELF64 programs enter through `syscall`/`sysret` (STAR/LSTAR/EFER.SCE) while
the kernel stays in long mode. `int 0x80` for 32-bit programs is unchanged.
Linux i386 personalities under permanent stay use a returnable
`lx_syscall_body` (no `iretd`), so `lxhello` works on `os-lm64.img` (#221).

## Changes

- GDT STAR block (`0xD8`…`0xF8`) and MSR setup on `lm_enter_perm`.
- ELF64 loader (`EM_X86_64`, PT_LOAD in the program area); requires `lm_perm`.
- `syscall64_entry` maps `rax`/`rdi`/`rsi`/`rdx` onto the 32-bit native table
  through `lm64_call32`; pointer checks refuse kernel addresses.
- `programs/hello64.asm`; checks `hello64`, `hello64-badptr` (lm64 flavour).
- Linux stay body; BSD/Win32 under stay still skipped on lm64.

## Checks

- `hello64: PASS`, `hello64-badptr: PASS` (`REGRESS_FLAVOUR=lm64`)
- `lx-hello` on both flavours
- Full `tools/regress.sh` i386 + lm64

## Limits

- BSD CF/stack under stay and Win32 host under stay are follow-ups.
- ELF64 only while `lm_perm` is set (lm64 / after `lmboot`).
