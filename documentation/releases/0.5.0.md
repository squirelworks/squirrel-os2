# 0.5.0 — Pipes and redirection

- Date: 2026-10-30
- Changes:
  - `kernel/shell.asm`: pipeline driver with `|` (any number of stages), `>`, `>>` and `<`
  - Console capture mode in `putc` (32 KB buffers at `0x60000`/`0x68000`); `cls` and the apps' exit banner are skipped while capturing
  - `SYS_GETC` reads redirected input and returns `-1` at its end; the calculators' line reader takes lines from it and quits at the end
  - `echo <text>` built-in command
  - `cat` and `wc` without a file name read their input (a pipe, `< file`, or the keyboard until Esc)
  - Command line grows from 60 to 120 characters
  - Fix: column padding (`ls`, `ps`) is computed from the captured text while capturing, which kept `ls > file` from hanging
  - Regression checks: nine `sh-*` checks (redirect, append, three-stage pipe, calc from a file, quiet capture, `ls` piped, and the three error messages)
- Status: implemented
- Design: `documentation/kernel/shell.md`
