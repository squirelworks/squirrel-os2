# 0.8.1 — Localization runtime

- Date: 2026-10-30
- Changes:
  - `tools/mkstrings.py` builds `kernel/strings.inc` from `localization/*/strings.txt`
  - `kernel/lang.asm`: a current-language table with English fallback, and `lang [code]` to show or switch language at runtime (`en`, `la`, `tlh`)
  - The banner name, prompt, `ls` header, `Not found`, `Unknown command`, `keys` prompt and `systest` result come from the tables
  - New keys `lang_now` and `lang_bad` in all three languages
  - `autoexec.bat` can set the language at boot
  - `tools/regress.sh` checks that `strings.inc` is up to date; new checks `lang-show`, `lang-la`, `lang-tlh`, `lang-bad`, `lang-banner`, `lang-systest`, `lang-autoexec`
- Status: implemented
- Design: `documentation/kernel/localization.md`

Next: better crash reporting (0.8.2).
