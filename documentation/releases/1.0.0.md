# 1.0.0 — Usable minimal system

- Date: 2026-10-31
- Goal (from `ROADMAP.md`): a usable minimal system. It boots, it has a file system and a file browser, and it runs `edit`, `vedit`, `draw` and the calculator suite that exists today (`calc`, `sci`, `matrix`).
- What 1.0.0 is: the 0.9.3 system, tagged. This release adds no features. Its changes are:
  - **Version.** The banner says `Squirrel-OS/2 1.0.0`; `ver-banner` and `lang-banner` expect it.
  - **One-boot walk.** The `walk-1.0` check in `tools/regress.sh` (1.0-walk) runs every 1.0 application in a single boot:
    - `calc` evaluates `2 + 2`;
    - `edit` saves a file;
    - `draw` and `files` open and quit;
    - the calculator history and the saved file are read back, and `systest` still passes.
  - **Documentation.**
    - `specifications.md` (1.0-spec) lists what the system does and its intentional limits.
    - The entry-point docs (1.0-docs) describe the system that boots.
- How to build and run: `tools/build.sh`, then `tools/run.sh`. See `guides/getting-started.md`.
- Tested on:
  - QEMU (hard disk and floppy, 4 MB to 128 MB): `tools/regress.sh`, 183 checks.
  - Bochs 2.7 with its legacy BIOS: `tools/bochs_smoke.sh`.
  - Not yet on VirtualBox, VMware or real hardware.
- Known limitations: the 0.9.3 table in `specifications.md`. The main ones:
  - Scheduling is cooperative.
  - Everything runs in ring 0.
  - The x87 state is not saved on a process switch.
  - There is no seek.
  - `graph`, `diff` and `topo` are scaffolds.
- Known bugs: none open (`knownbugs.md`).

- Status: implemented (git tag `v1.0.0` pending)
