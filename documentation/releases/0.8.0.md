# 0.8.0 — SQFS directories

- Date: 2026-10-30
- Changes:
  - SQFS entries can be directories. Each entry records its parent directory (bytes 28–29 of the directory entry, unused before), so older disks mount unchanged with everything in the root.
  - Every file name is now a path: `/` separates parts, a leading `/` starts at the root, and `.` and `..` work
  - Shell: `mkdir`, `cd`, `pwd`, `ls <dir>`. The prompt shows the current directory outside the root, and `mv` moves entries between directories (never a directory into itself).
  - `ls`, `run ls`, `SYS_READDIR` and the file browser list the current directory (a subdirectory's size reads as −1 through `SYS_READDIR`)
  - The loader falls back to the root, so programs run from any directory; the shell history always lives in `/shell.hist`
  - `tools/sqfs.py` understands directories: paths for `put`/`get`/`rm`, new `mkdir`, and `ls` prints full paths. It also no longer clears bytes 28–31 of every entry when it saves.
  - Fixed: `fstest` used `KSCRATCH+0x2800` as a buffer, which overwrote the in-memory shell history; it now uses `KSCRATCH+0xF000`
  - Regression checks: 12 `dir-*` checks
- Status: implemented
- Design: `documentation/kernel/filesystem.md`
