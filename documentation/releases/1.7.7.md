# 1.7.7 — Installer: the run install program

- Date: 2026-10-31
- TODO.md task: **I.5-ui**.
- Changes:
  - **`run install`** clears the screen, names the target disk and its size, says everything on it will be erased, and waits for one key: Enter installs, Esc cancels and writes nothing. Enter then runs the partition table, file system, copy and boot code steps without asking again, one line each (`... done` / `... failed`), and ends with `Installed. Remove the release disk and restart the computer.` A failed step stops the run. It can be started from a batch file (`run install` on a line). With no target, no IDE boot disk or no data disk it says so and writes nothing (`kernel/install.asm`).
  - **Localized.** The texts are the new `inst_*` keys in `localization/en`, `la` and `tlh`; `kernel/strings.inc` is regenerated.
  - The shell commands of I.1 to I.4 now share the same quiet routines with the program (`ins_do_part`, `ins_do_format`, `ins_do_kernel`, `ins_do_files`, `ins_do_boot`); their behaviour is unchanged.
  - Banner `1.7.7`.
  - Regression checks, on a second blank 16 MiB scratch image: `inst-esc` and `inst-esc-blank` (Esc at the question; the image is still all zeros on the host), `inst-la`, `inst-tlh`, `inst-run` (a batch file runs `run install`; all four steps report done), `inst-boots` (the result boots as the only disk).
- Known limitations:
  - BIOS boot and IDE disks only; the boot disk must be an IDE disk. Tested in QEMU only.
- Status: implemented
