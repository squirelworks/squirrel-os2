# 0.1.1 — System call interface

- Date: 2026-10-30
- Changes:
  - `int 0x80` trap gate (DPL 3) with bounds-checked dispatch table (`kernel/syscall.asm`)
  - Calls: `putc` (0), `puts` (1), `getc` (2, blocking), `yield` (3); unknown numbers return -1
  - ABI: number in `eax`, args in `ebx`/`ecx`/`edx`, result in `eax`, all else preserved
  - Keyboard IRQ now queues scancodes in a ring; the shell loop handles them outside interrupt context
  - Shell commands `systest` (self-test) and `keys` (getc/putc echo)
  - `putc` handles backspace and preserves all registers
  - `tools/qemu_screen.py` + `tools/regress.sh`: headless QEMU regression run
  - Fixes found while testing:
    - `ls` printed garbage after the first entry (`putc` clobbered `ebx`)
    - A command typed after a longer one was not recognised (command line not re-terminated)
    - `calc` subtraction/division gave wrong results (`atoi` clobbered the first operand)
    - `calc` division hung the machine (`cdq` overwrote the divisor, raising #DE)
- Status: implemented
- Known limitations: see `kernel/syscalls.md` and `knownbugs.md`
- Design: `documentation/kernel/syscalls.md`

Build/run:

```bash
cd kernel
nasm -f bin boot.asm -o boot.bin
nasm -f bin pm.asm -o pm.bin
cat boot.bin pm.bin > os.img
qemu-system-i386 -drive format=raw,file=os.img
```

Regression: `tools/regress.sh`
