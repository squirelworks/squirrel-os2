# 1.9.9 — Priority scheduling

- Date: 2026-11-01
- TODO.md task: **W.1-prio**.
- Changes:
  - Each process has a priority `0..3` (`PCB_PRIO`, default 1). `proc_switch` runs the highest READY priority; equals take turns.
  - `SYS_SETPRIO` (32) sets the caller's priority. `ps` prints `prio N` on each row.
  - `run priotest` keeps a low-priority child from running until the parent drops its priority (`prio: PASS`).
  - Banner `1.9.9`.
  - Regression check: `prio`.
- Known limitations:
  - No aging: a busy high-priority process still starves lower ones until it blocks or lowers itself.
- Status: implemented
- Design: `kernel/processes.md`
