# 0.3.3 — Drawing program polish

- Date: 2026-10-30
- Changes:
  - `draw` rewritten as its own module (`kernel/draw.asm`), running as a process like the other apps
  - Canvas grown from 32 × 10 to 64 × 18 and drawn in place with a border (resolves KB-7 for `draw`)
  - Pen down/up, brush character choice, lines (Bresenham), rectangle outlines and 4-connected flood fill
  - Load/save as a plain text file: `run draw <file>`, Ctrl+S / F2, save-as prompt, unsaved-changes prompt on quit
  - Status line (position, brush, pen, file, modified flag, pending corner) and a message for every action
  - Old draw mode removed from the shell's keyboard dispatch; `app_host` simplified
  - Regression checks: `draw-unsaved`, `draw-rect` (rectangle + fill + save + `cat`), `draw-line`, `draw-reload`
- Status: implemented
- Design: `documentation/apps/draw.md`

Next: program loader (0.3.0, later renumbered 0.4.0).
