# Squirrel-OS/2 Planned Milestones

## Path to 3.0 — 64-bit Warp

Version 3.0.0 is Squirrel-OS/2 as a 64-bit operating system that retains the Warp character while gaining the scale and services expected of a contemporary desktop OS.

Target: able to be considered alongside Linux, macOS, and Windows for general use.

### 2.x bridge
- 2.1 64-bit kernel bring-up
- 2.2 64-bit paging
- 2.3 Multi-core scheduler
- 2.4 UEFI boot
- 2.5 Modern storage/USB
- 2.6 64-bit userland ABI
- 2.7 Port desktop to 64-bit
- 2.8 Networking
- 2.9 Package manager and self-hosting

### 3.0.0
64-bit preemptive kernel, mature object desktop, journaling FS, networking, self-hosting toolchain, daily-driver applications and drivers. Original code. Peer to contemporary desktop OSes.
